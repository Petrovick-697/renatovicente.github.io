Passo 1 · Estrutura admitida

A ordem na reta real

Representamos os números reais por pontos de uma reta orientada. Escrever \(a < b\) significa que \(a\) está à esquerda de \(b.\) A relação \(a \le b\) permite também a igualdade.

Admitimos conhecidas as operações de corpo em \(\mathbb{R}\) e sua compatibilidade com a ordem. A ordem é reflexiva, antissimétrica e transitiva: \(a \le a;\) de \(a \le b\) e \(b \le a\) resulta \(a = b;\) e de \(a \le b \le c\) resulta \(a \le c.\) Além disso, quaisquer dois reais são comparáveis.

\[a \le b, c \le d \implies a + c \le b + d\] \[a \le b, c > 0 \implies ca \le cb\] \[a \le b, c < 0 \implies cb \le ca\]

Uma multiplicação positiva preserva a ordem; uma negativa a inverte. Se \(c = 0,\) os dois produtos são zero. A bancada mostra esses três casos.

Para conversar

  • O que acontece com a distância entre os pontos quando \(|c|\) aumenta?
  • Por que dividir uma desigualdade por um número negativo exige inverter seu sentido?

Livro: propriedades da ordem, pp. 15–16.

Passo 2 · Definição 1.1.1

Quais extremos pertencem ao intervalo?

Para \(a \le b,\) um intervalo é um conjunto de pontos que satisfaz uma condição de ordem. Os colchetes incluem o extremo; os parênteses o excluem.

\[(a, b) = \{x \in \mathbb{R} : a < x < b\}\] \[[a, b] = \{x \in \mathbb{R} : a \le x \le b\}\] \[[a, b) = \{x \in \mathbb{R} : a \le x < b\}\] \[(a, b] = \{x \in \mathbb{R} : a < x \le b\}\]

Os intervalos \([a, +\infty )\) e \((a, +\infty )\) são semirretas; analogamente definimos \((-\infty , b]\) e \((-\infty , b).\) Os símbolos \(\pm \infty \) não são números reais e não são extremos incluídos. O intervalo \((-\infty , +\infty )\) é \(\mathbb{R}.\)

Quando \(a = b,\) temos \([a,a]=\{a\}.\) As outras três escolhas dão o conjunto vazio, pois nenhuma delas permite simultaneamente as duas desigualdades.

Livro: definição 1.1.1, p. 16.

Exercícios · Intervalos
  1. Escreva como intervalo o conjunto dos \(x\) tais que \(-2 < x \le 4.\) O ponto \(-2\) pertence a ele?
    Ver resolução
    O intervalo é \((-2, 4].\) O ponto \(-2\) não pertence, porque a primeira desigualdade é estrita. O ponto \(4\) pertence.
  2. Determine \([3, 3]\) e \((3, 3].\)
    Ver resolução
    \([3, 3] = \{3\}.\) Para pertencer a \((3, 3],\) seria necessário \(3 < x \le 3,\) o que é impossível. Logo \((3, 3] = \varnothing .\)
Passo 3 · Definição 1.1.2

O módulo registra uma distância

O módulo de \(x\) é sua distância até zero:

\[|x|=\begin{cases}x,&x\ge0,\\-x,&x<0.\end{cases}\]

Propriedades

Para todos \(x, y \in \mathbb{R},\) valem \(|-x| = |x|, |x| \ge 0, x \le |x|\) e \(|xy| = |x||y|.\) Além disso, \(|x| = 0\) se, e somente se, \(x = 0.\)

O sinal de \(x\) indica o lado da origem. O número \(|x|\) registra apenas a distância. Por isso os pontos \(x\) e \(-x\) têm o mesmo módulo.

Livro: definição 1.1.2 e propriedades subsequentes, p. 16. As provas abaixo explicitam os exercícios propostos nessa página.

Demonstração

  1. Se \(x \ge 0, |x| = x \ge 0;\) se \(x < 0, |x| = -x > 0.\) Esses dois casos também mostram que \(|x| = 0\) equivale a \(x = 0.\)
  2. Para \(x \ge 0,\) temos \(|-x| = x = |x|.\) Para \(x < 0,\) temos \(-x > 0,\) de modo que \(|-x| = -x = |x|.\)
  3. Se \(x \ge 0, x = |x|.\) Se \(x < 0, x < 0 < -x = |x|.\) Portanto \(x \le |x|\) em ambos os casos.
  4. Se \(x\) ou \(y\) é zero, a identidade do produto vale. Se ambos são positivos, \(|xy| = xy = |x||y|.\) Se ambos são negativos, \(|xy| = xy = (-x)(-y) = |x||y|.\) Se têm sinais opostos, \(|xy| = -xy;\) nesse caso exatamente um dos fatores de \(|x||y|\) recebe um sinal negativo, e o produto também é \(-xy.\)
Passo 4 · Exemplo 1.1.3

Uma desigualdade de distância

A distância entre \(x\) e \(a\) é \(|x - a|.\) Dado \(\varepsilon > 0,\) os pontos a uma distância menor que \(\varepsilon \) de \(a\) formam o intervalo aberto de centro \(a\) e raio \(\varepsilon .\)

Equivalência

\[|x-a|<\varepsilon\iff a-\varepsilon<x<a+\varepsilon.\]

Hipóteses: \(a,x\in\mathbb{R}\) e \(\varepsilon>0.\)

Para todo \(R \ge 0,\) vale também \(|x - a| \le R\) se, e somente se, \(a - R \le x \le a + R.\) Quando \(R = 0,\) ambas as condições equivalem a \(x = a.\) Para \(|x - a| > \varepsilon ,\) obtemos as duas semirretas exteriores: \(x < a - \varepsilon \) ou \(x > a + \varepsilon .\)

A forma \(0 < |x - a| < \varepsilon \) exclui também o centro \(a.\) Essa vizinhança perfurada será usada ao definir pontos de acumulação.

Livro: exemplo 1.1.3, pp. 16–17.

Demonstração

  1. Para todo \(t \in \mathbb{R}, -|t| \le t \le |t|.\) Assim, \(|t| < \varepsilon \) implica \(-\varepsilon < t < \varepsilon .\)
  2. Reciprocamente, suponha \(-\varepsilon < t < \varepsilon .\) Se \(t \ge 0, |t| = t < \varepsilon .\) Se \(t < 0,\) a desigualdade \(-\varepsilon < t\) dá \(-t < \varepsilon ,\) isto é, \(|t| < \varepsilon .\)
  3. Aplique a equivalência anterior a \(t = x - a\) e some a aos três termos de \(-\varepsilon < x - a < \varepsilon .\) Isso produz \(a - \varepsilon < x < a + \varepsilon .\) Cada passagem é reversível.

Versão não estrita, incluindo raio zero. Se \(|t| \le R,\) então \(-R \le -|t| \le t \le |t| \le R.\) Reciprocamente, de \(-R \le t \le R\) obtemos \(|t| = t \le R\) quando \(t \ge 0\) e \(|t| = -t \le R\) quando \(t < 0.\) Logo, para todo \(R \ge 0, |t| \le R \iff -R \le t \le R.\) Aplique a \(t = x - a.\) Para \(R = 0,\) a condição \(-R \le t \le R\) impõe \(t = 0.\)

Passo 5 · Desigualdade (1.1.2)

Somar dois deslocamentos

Desigualdade triangular

\[\forall a, b \in \mathbb{R}, |a + b| \le |a| + |b|.\]

O deslocamento total \(a + b\) pode sofrer cancelamento. A soma \(|a| + |b|\) conta os comprimentos dos dois deslocamentos, independentemente de seus sentidos.

Na figura, \(a\) está entre \(-|a|\) e \(|a|,\) e \(b\) entre \(-|b|\) e \(|b|.\) Ao somar as duas inclusões, o ponto \(a + b\) fica entre \(-(|a| + |b|)\) e \(|a| + |b|.\)

Para conversar

  • Escolha \(a\) e \(b\) com sinais opostos. Onde a desigualdade pode ser estrita?
  • Que parte do argumento vale para qualquer par de reais, mesmo quando você não conhece seus valores?

Livro: desigualdade triangular e demonstração, pp. 17–18.

Demonstração

  1. Pelas propriedades do módulo, \(-|a| \le a \le |a|.\)
  2. Também \(-|b| \le b \le |b|.\) A compatibilidade da ordem com a soma permite somar os membros correspondentes.
  3. Obtemos \(-(|a| + |b|) \le a + b \le |a| + |b|.\) Como \(|a| + |b| \ge 0,\) a equivalência entre módulo e intervalo fechado fornece \(|a + b| \le |a| + |b|.\)

O argumento usa apenas propriedades válidas para reais arbitrários. Os parâmetros da figura escolhem um exemplo dessas mesmas relações.

Exercícios · Desigualdade triangular
  1. Dê um exemplo em que \(|a + b| < |a| + |b|\) e outro em que ocorre igualdade.
    Ver resolução
    Para \(a = 4\) e \(b = -3,\) temos \(|a + b| = 1 < 7 = |a| + |b|.\) Para \(a = 4\) e \(b = 3,\) os dois lados valem \(7.\)
  2. Demonstre que \(|a + b + c| \le |a| + |b| + |c|\) para todos \(a, b, c \in \mathbb{R}.\)
    Ver resolução
    Aplique a desigualdade triangular primeiro a \((a + b) + c: |a + b + c| \le |a + b| + |c|.\) Uma segunda aplicação dá \(|a + b| \le |a| + |b|.\) Substituindo essa cota na primeira desigualdade, chega-se ao resultado.
  3. Prove que ocorre igualdade na desigualdade triangular se, e somente se, \(ab \ge 0.\)
    Ver resolução
    Os dois lados são não negativos, então são iguais exatamente quando seus quadrados são iguais. A diferença dos quadrados é \((|a| + |b|)^{2} - (a + b)^{2} = 2(|a||b| - ab) = 2(|ab| - ab).\) Ela é zero exatamente quando \(|ab| = ab,\) isto é, quando \(ab \ge 0.\)
Passo 6 · Proposição 1.1.5

Comparar duas distâncias à origem

Desigualdade triangular reversa

\[\forall a, b \in \mathbb{R}, ||a| - |b|| \le |a - b|.\]

A diferença entre as distâncias de \(a\) e \(b\) até zero é limitada pela distância entre a e \(b.\) Para demonstrar isso, escrevemos a como \((a - b) + b\) e aplicamos a desigualdade que acabamos de provar.

Primeiro controlamos \(|a| - |b|.\) Depois trocamos os papéis de \(a\) e \(b\) para controlar o seu oposto. As duas cotas produzem o módulo da diferença.

Livro: proposição 1.1.5 e equações (1.1.4)–(1.1.6), p. 18.

Demonstração

  1. Como \(a = (a - b) + b,\) a desigualdade triangular dá \(|a| \le |a - b| + |b|.\) Subtraindo \(|b|,\) obtemos \(|a| - |b| \le |a - b|.\)
  2. Trocando \(a\) e \(b,\) obtemos \(|b| - |a| \le |b - a| = |a - b|.\) Multiplicar por \(-1\) inverte a ordem: \(-|a - b| \le |a| - |b|.\)
  3. Juntando as duas cotas, \(-|a - b| \le |a| - |b| \le |a - b|.\) Pela equivalência do passo 4 com desigualdades não estritas, isso é \(||a| - |b|| \le |a - b|.\)
Exercício · Usar a desigualdade

Se \(|x - a| < \varepsilon ,\) com \(\varepsilon > 0,\) mostre que \(||x| - |a|| < \varepsilon .\)

Ver resolução
A desigualdade triangular reversa fornece \(||x| - |a|| \le |x - a|.\) Como, por hipótese, \(|x - a| < \varepsilon ,\) a transitividade dá \(||x| - |a|| < \varepsilon .\)

Cola da aula

Distância: \(|x - a|.\) Intervalo de raio \(\varepsilon > 0: |x - a| < \varepsilon \iff x \in (a - \varepsilon , a + \varepsilon ).\) Desigualdade triangular: \(|a + b| \le |a| + |b|.\) Desigualdade reversa: \(||a| - |b|| \le |a - b|.\)
