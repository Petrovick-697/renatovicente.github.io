Passo 1 · Estrutura admitida

A ordem na reta real

Representamos os números reais por pontos de uma reta orientada. Escrever a < b significa que a está à esquerda de b. A relação a ≤ b permite também a igualdade.

Admitimos conhecidas as operações de corpo em ℝ e sua compatibilidade com a ordem. A ordem é reflexiva, antissimétrica e transitiva: a ≤ a; de a ≤ b e b ≤ a resulta a = b; e de a ≤ b ≤ c resulta a ≤ c. Além disso, quaisquer dois reais são comparáveis.

a ≤ b, c ≤ d ⇒ a + c ≤ b + d
a ≤ b, c > 0 ⇒ ca ≤ cb
a ≤ b, c < 0 ⇒ cb ≤ ca

Uma multiplicação positiva preserva a ordem; uma negativa a inverte. Se c = 0, os dois produtos são zero. A bancada mostra esses três casos.

Para conversar

  • O que acontece com a distância entre os pontos quando |c| aumenta?
  • Por que dividir uma desigualdade por um número negativo exige inverter seu sentido?

Livro: propriedades da ordem, pp. 15–16.

Passo 2 · Definição 1.1.1

Quais extremos pertencem ao intervalo?

Para a ≤ b, um intervalo é um conjunto de pontos que satisfaz uma condição de ordem. Os colchetes incluem o extremo; os parênteses o excluem.

(a, b) = {x ∈ ℝ : a < x < b}
[a, b] = {x ∈ ℝ : a ≤ x ≤ b}
[a, b) = {x ∈ ℝ : a ≤ x < b}
(a, b] = {x ∈ ℝ : a < x ≤ b}

Os intervalos [a, +∞) e (a, +∞) são semirretas; analogamente definimos (−∞, b] e (−∞, b). Os símbolos ±∞ não são números reais e não são extremos incluídos. O intervalo (−∞, +∞) é ℝ.

Quando a = b, temos [a, a] = {a}. As outras três escolhas dão o conjunto vazio, pois nenhuma delas permite simultaneamente as duas desigualdades.

Livro: definição 1.1.1, p. 16.

Exercícios · Intervalos
  1. Escreva como intervalo o conjunto dos x tais que −2 < x ≤ 4. O ponto −2 pertence a ele?
    Ver resolução
    O intervalo é (−2, 4]. O ponto −2 não pertence, porque a primeira desigualdade é estrita. O ponto 4 pertence.
  2. Determine [3, 3] e (3, 3].
    Ver resolução
    [3, 3] = {3}. Para pertencer a (3, 3], seria necessário 3 < x ≤ 3, o que é impossível. Logo (3, 3] = ∅.
Passo 3 · Definição 1.1.2

O módulo registra uma distância

O módulo de x é sua distância até zero:

|x| = x, se x ≥ 0;
|x| = −x, se x < 0.

Propriedades

Para todos x, y ∈ ℝ, valem |−x| = |x|, |x| ≥ 0, x ≤ |x| e |xy| = |x||y|. Além disso, |x| = 0 se, e somente se, x = 0.

O sinal de x indica o lado da origem. O número |x| registra apenas a distância. Por isso os pontos x e −x têm o mesmo módulo.

Livro: definição 1.1.2 e propriedades subsequentes, p. 16. As provas abaixo explicitam os exercícios propostos nessa página.

Demonstração

  1. Se x ≥ 0, |x| = x ≥ 0; se x < 0, |x| = −x > 0. Esses dois casos também mostram que |x| = 0 equivale a x = 0.
  2. Para x ≥ 0, temos |−x| = x = |x|. Para x < 0, temos −x > 0, de modo que |−x| = −x = |x|.
  3. Se x ≥ 0, x = |x|. Se x < 0, x < 0 < −x = |x|. Portanto x ≤ |x| em ambos os casos.
  4. Se x ou y é zero, a identidade do produto vale. Se ambos são positivos, |xy| = xy = |x||y|. Se ambos são negativos, |xy| = xy = (−x)(−y) = |x||y|. Se têm sinais opostos, |xy| = −xy; nesse caso exatamente um dos fatores de |x||y| recebe um sinal negativo, e o produto também é −xy.
Passo 4 · Exemplo 1.1.3

Uma desigualdade de distância

A distância entre x e a é |x − a|. Dado ε > 0, os pontos a uma distância menor que ε de a formam o intervalo aberto de centro a e raio ε.

Equivalência

|x − a| < ε ⇔ a − ε < x < a + ε.Hipóteses: a, x ∈ ℝ e ε > 0.

Para todo R ≥ 0, vale também |x − a| ≤ R se, e somente se, a − R ≤ x ≤ a + R. Quando R = 0, ambas as condições equivalem a x = a. Para |x − a| > ε, obtemos as duas semirretas exteriores: x < a − ε ou x > a + ε.

A forma 0 < |x − a| < ε exclui também o centro a. Essa vizinhança perfurada será usada ao definir pontos de acumulação.

Livro: exemplo 1.1.3, pp. 16–17.

Demonstração

  1. Para todo t ∈ ℝ, −|t| ≤ t ≤ |t|. Assim, |t| < ε implica −ε < t < ε.
  2. Reciprocamente, suponha −ε < t < ε. Se t ≥ 0, |t| = t < ε. Se t < 0, a desigualdade −ε < t dá −t < ε, isto é, |t| < ε.
  3. Aplique a equivalência anterior a t = x − a e some a aos três termos de −ε < x − a < ε. Isso produz a − ε < x < a + ε. Cada passagem é reversível.

Versão não estrita, incluindo raio zero. Se |t| ≤ R, então −R ≤ −|t| ≤ t ≤ |t| ≤ R. Reciprocamente, de −R ≤ t ≤ R obtemos |t| = t ≤ R quando t ≥ 0 e |t| = −t ≤ R quando t < 0. Logo, para todo R ≥ 0, |t| ≤ R ⇔ −R ≤ t ≤ R. Aplique a t = x − a. Para R = 0, a condição −R ≤ t ≤ R impõe t = 0.

Passo 5 · Desigualdade (1.1.2)

Somar dois deslocamentos

Desigualdade triangular

∀a, b ∈ ℝ,   |a + b| ≤ |a| + |b|.

O deslocamento total a + b pode sofrer cancelamento. A soma |a| + |b| conta os comprimentos dos dois deslocamentos, independentemente de seus sentidos.

Na figura, a está entre −|a| e |a|, e b entre −|b| e |b|. Ao somar as duas inclusões, o ponto a + b fica entre −(|a| + |b|) e |a| + |b|.

Para conversar

  • Escolha a e b com sinais opostos. Onde a desigualdade pode ser estrita?
  • Que parte do argumento vale para qualquer par de reais, mesmo quando você não conhece seus valores?

Livro: desigualdade triangular e demonstração, pp. 17–18.

Demonstração

  1. Pelas propriedades do módulo, −|a| ≤ a ≤ |a|.
  2. Também −|b| ≤ b ≤ |b|. A compatibilidade da ordem com a soma permite somar os membros correspondentes.
  3. Obtemos −(|a| + |b|) ≤ a + b ≤ |a| + |b|. Como |a| + |b| ≥ 0, a equivalência entre módulo e intervalo fechado fornece |a + b| ≤ |a| + |b|.

O argumento usa apenas propriedades válidas para reais arbitrários. Os parâmetros da figura escolhem um exemplo dessas mesmas relações.

Exercícios · Desigualdade triangular
  1. Dê um exemplo em que |a + b| < |a| + |b| e outro em que ocorre igualdade.
    Ver resolução
    Para a = 4 e b = −3, temos |a + b| = 1 < 7 = |a| + |b|. Para a = 4 e b = 3, os dois lados valem 7.
  2. Demonstre que |a + b + c| ≤ |a| + |b| + |c| para todos a, b, c ∈ ℝ.
    Ver resolução
    Aplique a desigualdade triangular primeiro a (a + b) + c: |a + b + c| ≤ |a + b| + |c|. Uma segunda aplicação dá |a + b| ≤ |a| + |b|. Substituindo essa cota na primeira desigualdade, chega-se ao resultado.
  3. Prove que ocorre igualdade na desigualdade triangular se, e somente se, ab ≥ 0.
    Ver resolução
    Os dois lados são não negativos, então são iguais exatamente quando seus quadrados são iguais. A diferença dos quadrados é (|a| + |b|)² − (a + b)² = 2(|a||b| − ab) = 2(|ab| − ab). Ela é zero exatamente quando |ab| = ab, isto é, quando ab ≥ 0.
Passo 6 · Proposição 1.1.5

Comparar duas distâncias à origem

Desigualdade triangular reversa

∀a, b ∈ ℝ,   ||a| − |b|| ≤ |a − b|.

A diferença entre as distâncias de a e b até zero é limitada pela distância entre a e b. Para demonstrar isso, escrevemos a como (a − b) + b e aplicamos a desigualdade que acabamos de provar.

Primeiro controlamos |a| − |b|. Depois trocamos os papéis de a e b para controlar o seu oposto. As duas cotas produzem o módulo da diferença.

Livro: proposição 1.1.5 e equações (1.1.4)–(1.1.6), p. 18.

Demonstração

  1. Como a = (a − b) + b, a desigualdade triangular dá |a| ≤ |a − b| + |b|. Subtraindo |b|, obtemos |a| − |b| ≤ |a − b|.
  2. Trocando a e b, obtemos |b| − |a| ≤ |b − a| = |a − b|. Multiplicar por −1 inverte a ordem: −|a − b| ≤ |a| − |b|.
  3. Juntando as duas cotas, −|a − b| ≤ |a| − |b| ≤ |a − b|. Pela equivalência do passo 4 com desigualdades não estritas, isso é ||a| − |b|| ≤ |a − b|.
Exercício · Usar a desigualdade

Se |x − a| < ε, com ε > 0, mostre que ||x| − |a|| < ε.

Ver resolução
A desigualdade triangular reversa fornece ||x| − |a|| ≤ |x − a|. Como, por hipótese, |x − a| < ε, a transitividade dá ||x| − |a|| < ε.

Cola da aula

Distância: |x − a|. Intervalo de raio ε > 0: |x − a| < ε ⇔ x ∈ (a − ε, a + ε). Desigualdade triangular: |a + b| ≤ |a| + |b|. Desigualdade reversa: ||a| − |b|| ≤ |a − b|.
