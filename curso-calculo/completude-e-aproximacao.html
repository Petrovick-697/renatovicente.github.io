Fatos básicos · A reta real

Completude
e aproximação

Um conjunto pode se aproximar de um extremo sem contê-lo. Para conjuntos reais não vazios e limitados superiormente, a completude garante a existência do supremo. A propriedade arquimediana permite construir aproximações dentro de qualquer tolerância positiva.

Usaremos ℕ = {0, 1, 2, …} e ℕ⁺ = {1, 2, …}. Uma afirmação “para todo ε > 0” exige um argumento que funcione para qualquer ε positivo. Nas bancadas com tolerância, escolha ε ou δ e acompanhe a construção do ponto que a prova exige.

Passo 1 · Definições 1.1.6 e 1.1.9

Limitar um conjunto

Uma cota superior de A ⊂ ℝ é um real M tal que x ≤ M para todo x ∈ A. Se alguma cota superior existe, A é limitado superiormente. Uma cota inferior é um real m tal que m ≤ x para todo x ∈ A.

O conjunto A é limitado se existem cotas nos dois sentidos. Equivalentemente, existe R > 0 tal que |x| ≤ R para todo x ∈ A: de m ≤ x ≤ M, basta tomar R = max{|m|, |M|} + 1. Reciprocamente, |x| ≤ R implica −R ≤ x ≤ R.

Supremo e máximo

Para A ≠ ∅, um real L é seu supremo se é uma cota superior e L ≤ M para toda cota superior M. Escrevemos L = sup A. Se L ∈ A, ele é também o máximo: L = max A.

Por exemplo, sup(0, 1) = 1 e sup(0, 1] = 1. Apenas o segundo conjunto tem máximo. Mudar a inclusão do extremo não muda seu valor como menor cota superior.

Livro: definições 1.1.6, 1.1.9 e 1.1.12, pp. 18–19.

Passo 2 · Definição 1.1.10

Qualquer diminuição perde a cota

Caracterização do supremo

Sejam A ⊂ ℝ não vazio e limitado superiormente, e L ∈ ℝ. Então L = sup A se, e somente se, valem:

∀x ∈ A, x ≤ L;
∀ε > 0, ∃x ∈ A : L − ε < x.

A primeira condição diz que L é cota. A segunda diz que todo número estritamente menor que L deixa algum elemento de A acima dele.

Para A = (0, 1), dado ε > 0, podemos escolher x = 1 − min{ε/2, 1/2}. Esse ponto pertence a A e satisfaz 1 − ε < x < 1. A escolha funciona também quando ε é grande.

Livro: definições equivalentes 1.1.9–1.1.10 e observação 1.1.11, p. 19. A equivalência é demonstrada abaixo.

Demonstração da equivalência

  1. Suponha L = sup A. A primeira condição faz parte da definição. Dado ε > 0, o número L − ε é menor que a menor cota superior e, portanto, não é cota superior.
  2. Negar que L − ε seja cota significa: existe x ∈ A com L − ε < x. Isso prova a segunda condição.
  3. Reciprocamente, suponha as duas condições e seja M uma cota superior qualquer. Se M < L, tome ε = L − M > 0. A segunda condição fornece x ∈ A com M = L − ε < x, contradizendo que M é cota.
  4. Logo L ≤ M para toda cota superior M. Como a primeira condição garante que L é cota, L é a menor delas: L = sup A.
Passo 3 · Definições 1.1.14 e 1.1.15

O ínfimo por reflexão

O ínfimo de A ≠ ∅ é a maior cota inferior e se escreve inf A. Se pertence a A, é o mínimo, min A. Sua caracterização é:

m = inf A ⇔
∀x ∈ A, m ≤ x,   e
∀ε > 0, ∃x ∈ A : x < m + ε.

Relação entre ínfimo e supremo

Se A ≠ ∅ é limitado inferiormente e −A = {−x : x ∈ A}, então −A é limitado superiormente. Sempre que s = sup(−A) existe, inf A = −s.

A reflexão x ↦ −x inverte todas as desigualdades. Assim, o resultado de existência de supremos que adotaremos no próximo passo dará também a existência de ínfimos.

Livro: definições 1.1.14–1.1.15 e consequência da completude, p. 21.

Demonstração

  1. Se m₀ é uma cota inferior de A, então m₀ ≤ x para todo x ∈ A. Logo −x ≤ −m₀ e −A é limitado superiormente.
  2. Se s = sup(−A), então −x ≤ s para todo x ∈ A. Portanto −s ≤ x: o número −s é uma cota inferior de A.
  3. Se m é outra cota inferior de A, −m é cota superior de −A. Pela definição de s, s ≤ −m, isto é, m ≤ −s. Logo −s é a maior cota inferior de A.

Caracterização por ε. Se m = inf A, então m é cota inferior. Para todo ε > 0, m + ε > m não pode ser cota inferior; portanto existe x ∈ A com x < m + ε. Reciprocamente, suponha que m seja cota inferior e que essa condição valha para todo ε > 0. Se uma cota inferior m′ fosse maior que m, escolhendo ε = m′ − m > 0 obteríamos x ∈ A com x < m + ε = m′, contradizendo que m′ é cota inferior. Logo toda cota inferior m′ satisfaz m′ ≤ m, e m = inf A.

Passo 4 · Axioma da completude

A existência de um extremo real

Axioma da completude

Todo subconjunto não vazio de ℝ que é limitado superiormente possui supremo em ℝ.

Adotamos essa propriedade como axioma. A figura ilustra uma de suas consequências, cuja demonstração depende do axioma.

Uma consequência

Existe um único real s ≥ 0 tal que s² = 2. Denotamos esse número por √2.

Considere S = {x ∈ ℝ : x ≥ 0 e x² < 2}. Temos 1 ∈ S e 2 é uma cota superior. O axioma fornece s = sup S, com 1 ≤ s ≤ 2. Falta provar que s² = 2.

Livro: discussão de √2 e axioma da completude, pp. 20–21. A demonstração detalhada da existência abaixo é um desenvolvimento para a aula.

Demonstração da existência e unicidade

  1. O conjunto S é não vazio e limitado superiormente. Pela completude, existe s = sup S e 1 ≤ s ≤ 2.
  2. Se s² < 2, escolha h = min{1, (2 − s²)/(2(2s + 1))} > 0. Como h ≤ 1, temos 2sh + h² ≤ (2s + 1)h ≤ (2 − s²)/2. Logo (s + h)² < 2. Assim s + h ∈ S, contradizendo que s é cota superior.
  3. Se s² > 2, escolha h = min{s/2, (s² − 2)/(4s)} > 0. Então s − h > 0 e (s − h)² ≥ s² − 2sh ≥ (s² + 2)/2 > 2. Todo x ∈ S satisfaz x < s − h, pois x ≥ 0 e x² < 2. Portanto s − h é uma cota superior menor que s, contradizendo a minimalidade do supremo.
  4. Resta s² = 2. Se 0 ≤ t < s, então s² − t² = (s − t)(s + t) > 0. Portanto t² ≠ s². Esse argumento, com os papéis trocados se necessário, prova a unicidade da raiz não negativa.
Passo 5 · Racionais e irracionais

Uma aproximação racional não é uma igualdade

Irracionalidade de √2

Não existem inteiros p, q, com q ≠ 0, tais que √2 = p/q.

As frações 7/5 e 17/12 são aproximações de √2, mas seus quadrados não são 2. A demonstração precisa excluir toda fração, inclusive aquelas que não aparecem na bancada.

Usaremos o fato aritmético de que o quadrado de um inteiro ímpar é ímpar: (2k + 1)² = 2(2k² + 2k) + 1. Assim, se o quadrado de um inteiro é par, o inteiro também é par.

Livro: discussão e prova da irracionalidade, pp. 20–21. Aqui usamos a prova por paridade, em vez da prova por redução do denominador apresentada na foto.

Demonstração por contradição

  1. Suponha √2 = p/q, com p, q ∈ ℕ⁺ e a fração irredutível. Isso é possível se √2 for racional, pois ele é positivo.
  2. Elevando ao quadrado, p² = 2q². Logo p² é par, e o fato aritmético acima implica p = 2k para algum inteiro k.
  3. Substituindo, 4k² = 2q², de modo que q² = 2k². Assim q também é par.
  4. Os inteiros p e q seriam ambos divisíveis por 2, em contradição com a irredutibilidade. Portanto √2 é irracional.
Explorar aproximações racionais por bisseção

Em cada passo, subdividimos um intervalo de extremos racionais. Escolhemos a metade cujos extremos têm quadrados abaixo e acima de 2. A largura cai pela metade, enquanto √2 permanece no interior.

Proposições 1.1.16 e 1.1.17

Somar e multiplicar por um racional

Enunciados

Se r ∈ ℚ e α ∈ ℝ ∖ ℚ, então r + α é irracional. Se, além disso, r ≠ 0, então rα também é irracional.

A hipótese r ≠ 0 é necessária no produto: 0·α = 0 é racional. Para a soma, r pode ser zero.

A bancada fixa α = √2 e permite escolher os racionais r e q. Se tentássemos impor r + α = q, teríamos de identificar α com o racional q − r. No produto com r ≠ 0, a tentativa rα = q exigiria α = q/r.

Livro: proposições 1.1.16–1.1.17 e demonstrações, p. 22.

Demonstrações

  1. Soma. Suponha r + α = q ∈ ℚ. Então α = q − r. Como a diferença de dois racionais é racional, isso contradiz α ∉ ℚ.
  2. Produto. Suponha r ≠ 0 e rα = q ∈ ℚ. Dividindo por r, α = q/r ∈ ℚ, novamente uma contradição. Para r = 0 a divisão é impossível e a conclusão realmente falha.
Passo 6 · Teorema 1.1.18

Passos positivos ultrapassam qualquer cota

Propriedade arquimediana

Para quaisquer x, y ∈ ℝ com x > 0, existe n ∈ ℕ tal que nx > y.

O tamanho x do passo pode ser muito pequeno. A afirmação garante que um número finito de passos basta para ultrapassar qualquer y fixado.

Na prova, supomos que A = {nx : n ∈ ℕ} tem uma cota superior. Seu supremo L forneceria um múltiplo mx a menos de x de L. O múltiplo seguinte ultrapassaria L, produzindo a contradição.

Livro: teorema 1.1.18 e demonstração, p. 22.

Demonstração por contradição

  1. Fixe x > 0. Se a conclusão fosse falsa para algum y, teríamos nx ≤ y para todo n ∈ ℕ. Assim A = {nx : n ∈ ℕ} seria não vazio e limitado superiormente.
  2. Pela completude, existiria L = sup A. Use ε = x na caracterização do supremo: existe m ∈ ℕ tal que L − x < mx.
  3. Somando x, obtemos L < (m + 1)x. Mas (m + 1)x ∈ A, contradizendo que L é cota superior de A. Logo a conclusão vale para todo y ∈ ℝ.
Passo 7 · Corolário 1.1.19

Construir um recíproco menor que ε

Corolário

Para todo ε > 0 existe n ∈ ℕ⁺ tal que 1/n < ε.

A ordem dos quantificadores importa: primeiro alguém escolhe ε; depois escolhemos n, que pode depender de ε. Um único n não serve para todas as tolerâncias positivas.

Na bancada, ε = p/1000. A escolha n = ⌊1000/p⌋ + 1 garante n > 1/ε. A notação ⌊t⌋ significa o maior inteiro menor ou igual a t. A existência desse inteiro será justificada no argumento de densidade.

Livro: corolário 1.1.19, p. 22.

Demonstração

  1. Dado ε > 0, aplique a propriedade arquimediana a x = ε e y = 1. Existe n ∈ ℕ tal que nε > 1.
  2. Necessariamente n > 0. Divida a desigualdade por n e obtenha 1/n < ε.
Exercícios · Escolher uma testemunha
  1. Encontre um n que satisfaça 1/n < 1/100. O valor n = 100 serve?
    Ver resolução
    n = 101 serve, pois 1/101 < 1/100. O valor 100 produz igualdade e não satisfaz a desigualdade estrita.
  2. Prove que B = {1 − 1/n : n ∈ ℕ⁺} tem supremo 1 e não tem máximo.
    Ver resolução
    Para todo n ≥ 1, 1 − 1/n < 1, então 1 é cota superior e não pertence a B. Dado ε > 0, o corolário fornece n com 1/n < ε. Logo 1 − ε < 1 − 1/n ∈ B. Pela caracterização do supremo, sup B = 1. Como esse supremo não pertence ao conjunto, B não tem máximo.
Passo 8 · Definições 1.1.20–1.1.22

Encontrar outro ponto em toda vizinhança

Para a ∈ ℝ e δ > 0, escrevemos Bδ(a) = (a − δ, a + δ). Uma vizinhança de a é qualquer intervalo aberto que o contém. Um conjunto U ⊂ ℝ é aberto quando, para todo a ∈ U, existe δ > 0 com Bδ(a) ⊂ U.

Ponto de acumulação

O ponto a ∈ ℝ é de acumulação de A ⊂ ℝ quando

∀δ > 0, ∃x ∈ A : 0 < |x − a| < δ.

O ponto a pode pertencer a A ou estar fora dele. A desigualdade 0 < |x − a| exige que a vizinhança contenha outro ponto.

Consequência

Toda vizinhança de um ponto de acumulação de A contém infinitos pontos de A. Portanto conjuntos finitos não têm pontos de acumulação.

Livro: definições 1.1.20–1.1.22, p. 22; exemplos e exercício de infinitude, p. 23.

Demonstração da consequência

  1. Suponha a ponto de acumulação de A. Fixe δ > 0 e suponha, por contradição, que Bδ(a) contenha apenas finitos pontos de A distintos de a, chamados x₁, …, xₘ.
  2. Se m = 0, a própria vizinhança contradiz a definição de acumulação. Se m ≥ 1, todas as distâncias |xᵢ − a| são positivas, e o mínimo de uma lista finita dessas distâncias também é positivo.
  3. Tome η = min{δ/2, |x₁ − a|/2, …, |xₘ − a|/2} > 0. A vizinhança Bη(a) está contida em Bδ(a) e não contém nenhum dos xᵢ. Também não contém outros pontos de A distintos de a, pela escolha da lista.
  4. Isso contradiz a definição de ponto de acumulação. Logo Bδ(a) contém infinitos pontos de A. Todo intervalo aberto V que contém a inclui alguma Bδ(a): para V = (u, v), escolha δ > 0 menor que as distâncias aos extremos finitos. Assim toda vizinhança contém infinitos pontos de A. Se A for finito, isso é impossível, e A não tem pontos de acumulação.
Demonstrações dos exemplos da bancada

Intervalo (0, 1). O ponto 0 não pertence ao intervalo. Para todo δ > 0, escolha x = min{δ/2, 1/2}. Então 0 < x < 1 e |x| < δ; portanto 0 é ponto de acumulação.

Inteiros. Para qualquer a ∈ ℝ, se a ∈ ℤ, a vizinhança de raio 1/2 não contém outro inteiro. Se a ∉ ℤ, escolha os inteiros consecutivos k < a < k + 1 e um raio menor que min{a − k, k + 1 − a}. Essa vizinhança não contém inteiros. Assim ℤ não tem pontos de acumulação. A existência de k é justificada na prova do próximo passo.

Recíprocos. Para D = {1/n : n ∈ ℕ⁺}, o corolário do passo 7 mostra que 0 é ponto de acumulação, embora 0 ∉ D. Ele é o único: se a < 0, use o raio |a|/2. Se a > 0, escolha N com 1/N < a/2. Todos os termos com n ≥ N ficam abaixo de a/2. Restam apenas os finitos termos com n < N; escolha um raio menor que a/2 e que as distâncias positivas de a a esses termos, excluindo o próprio a se ele for um deles. A vizinhança não conterá outro ponto de D.

Intervalos em geral. Se A = (u, v), u < v, seus pontos de acumulação formam [u, v]. Dado δ > 0, para a = u ou a = v tome h = min{δ/2, (v − u)/2} > 0 e escolha, respectivamente, x = u + h ou x = v − h. Esses pontos pertencem a A e satisfazem 0 < |x − a| < δ. Para u < a < v, tome h = min{δ/2, (v − a)/2} e x = a + h. Se a < u, o raio (u − a)/2 dá uma vizinhança sem pontos de A; se a > v, use (a − v)/2. Isso prova as duas inclusões.

Passo 9 · Corolário 1.1.25

Um racional dentro de qualquer intervalo

Densidade dos racionais

Para quaisquer a, b ∈ ℝ com a < b, existe r ∈ ℚ tal que a < r < b.

Escolha uma malha de passo 1/n menor que a largura b − a. O primeiro ponto k/n estritamente à direita de a ainda ficará antes de b. O argumento funciona também para extremos negativos.

Dizemos que E ⊂ ℝ é denso em ℝ quando toda vizinhança de todo real contém um ponto de E. O enunciado garante essa propriedade para E = ℚ.

Livro: corolário 1.1.25, definição 1.1.26 e observação 1.1.27, p. 23. A prova abaixo explicita a escolha do inteiro para extremos de qualquer sinal.

Demonstração

  1. Fixe a < b. Pelo corolário do passo 7, escolha n ∈ ℕ⁺ tal que 1/n < b − a.
  2. Existe um inteiro k com k − 1 ≤ na < k. Para justificar: E = {j ∈ ℤ : j > na} é não vazio pela propriedade arquimediana e limitado inferiormente. Seja t = inf E. Escolha k ∈ E com k < t + 1/2. Se algum j ∈ E fosse menor que k, teríamos j ≤ k − 1 < t, uma contradição. Logo k é o menor elemento de E; portanto k − 1 ≤ na < k.
  3. Dividindo por n > 0, obtemos a < k/n ≤ a + 1/n < b. Assim r = k/n é o racional procurado.

O mesmo argumento estabelece a existência de ⌊u⌋ para qualquer real u: escolha k − 1 ≤ u < k e tome ⌊u⌋ = k − 1. Essa é a operação usada nos cálculos das bancadas.

Observação 1.1.27

Um irracional no mesmo intervalo

Densidade dos irracionais

Para quaisquer a < b, existe α ∈ ℝ ∖ ℚ tal que a < α < b.

Translade o intervalo por −√2, escolha um racional nele e desfaça a translação. A soma desse racional com √2 é irracional, como provamos no passo 5.

A conclusão envolve a existência de pontos de tipos diferentes em intervalos arbitrariamente pequenos. A classificação como racional ou irracional decorre da forma exata do número, independentemente da aproximação decimal mostrada.

Livro: observação 1.1.27, p. 23. A referência usa um produto com um irracional; aqui usamos uma translação para a demonstração.

Demonstração

  1. Como a − √2 < b − √2, a densidade dos racionais fornece q ∈ ℚ tal que a − √2 < q < b − √2.
  2. Some √2 aos três termos. O número α = q + √2 pertence a (a, b).
  3. Pela proposição sobre soma de racional e irracional, α ∉ ℚ. Logo os irracionais são densos em ℝ.

Todo real a é ponto de acumulação tanto de ℚ quanto dos irracionais: dado δ > 0, aplique os resultados ao intervalo (a, a + δ). O ponto obtido é diferente de a e está a uma distância menor que δ. Pela consequência do passo 8, toda vizinhança contém infinitos pontos de cada um desses conjuntos.

Cola da aula

Supremo: menor cota superior. Máximo: supremo que pertence ao conjunto. Ínfimo: maior cota inferior. Completude: existência de supremo para conjuntos reais não vazios e limitados superiormente. Acumulação: ∀δ > 0, ∃x ∈ A com 0 < |x − a| < δ. Densidade: todo intervalo aberto não vazio contém um ponto do conjunto.
