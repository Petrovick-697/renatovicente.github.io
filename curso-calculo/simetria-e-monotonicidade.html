Simetria e monotonicidade

Simetrias relacionam valores em pontos diferentes. A monotonicidade relaciona a ordem das entradas à das saídas. Combinada com uma homogeneidade por inteiros, ela determina uma função inteira a partir de um único valor.

A proposição final usa a densidade dos racionais, demonstrada na aula 02. A figura apresenta um ponto hipotético fora da reta e constrói o racional que o torna incompatível com as hipóteses.

Passo 1 · Definição 1.2.22

Refletir um ponto do gráfico

Um conjunto A ⊂ ℝ é simétrico em relação a zero quando x ∈ A implica −x ∈ A. Para f : A → ℝ com esse domínio, dizemos que f é par se f(−x) = f(x) para todo x ∈ A, e ímpar se f(−x) = −f(x) para todo x ∈ A.

Equivalência geométrica

f é par se, e somente se, seu gráfico é invariante pela reflexão (x,y) ↦ (−x,y). f é ímpar se, e somente se, seu gráfico é invariante pela simetria central (x,y) ↦ (−x,−y).

x² é par, x³ é ímpar e x² + x não é nenhuma das duas. A função nula é simultaneamente par e ímpar. Se 0 ∈ A e f é ímpar, f(0) = −f(0), de modo que f(0) = 0.

Livro: definição 1.2.22 e exemplo 1.2.23, pp. 29–30.

Demonstração

  1. Se f é par, a reflexão de qualquer (x,f(x)) é (−x,f(x)) = (−x,f(−x)), que pertence ao gráfico. Como a reflexão aplicada duas vezes é a identidade, o gráfico é invariante. Reciprocamente, se o gráfico é invariante, (−x,f(x)) pertence a ele; a unicidade da saída em −x dá f(−x) = f(x).
  2. Se f é ímpar, a simetria central leva (x,f(x)) a (−x,−f(x)) = (−x,f(−x)), também no gráfico. A transformação é sua própria inversa. Reciprocamente, a invariância põe (−x,−f(x)) no gráfico e a unicidade da saída dá f(−x) = −f(x).
Passo 2 · Definição 1.2.24

Repetir exige preservar o domínio

Seja f : A → ℝ. Um número T > 0 é um período quando, para todo x ∈ A, temos x ± T ∈ A e f(x ± T) = f(x). A condição sobre o domínio faz parte da definição.

Múltiplos inteiros de um período

Se T é período, então, para todo inteiro k e todo x ∈ A, x + kT ∈ A e f(x + kT) = f(x). Em particular, mT é período para todo inteiro m ≥ 1.

A bancada usa a parte fracionária {x} = x − ⌊x⌋, em todo ℝ. A igualdade {x + 1} = {x} será justificada no próximo resultado.

Livro: definições 1.2.24–1.2.25 e exemplo 1.2.26, p. 30.

Demonstração

  1. Para k = 0, a afirmação é x ∈ A e f(x) = f(x). Para k = 1, ela é parte da hipótese de periodicidade.
  2. Suponha x + kT ∈ A e f(x + kT) = f(x), com k ≥ 0. Aplicando a hipótese no ponto x + kT, obtemos x + (k + 1)T ∈ A e f(x + (k + 1)T) = f(x + kT) = f(x). A indução prova todos os k ≥ 0.
  3. A mesma indução, usando −T em cada passo, fornece x − jT ∈ A e f(x − jT) = f(x) para j ≥ 0. Portanto a afirmação vale para todo k ∈ ℤ. Fixado m ≥ 1, os casos k = ±m verificam as duas condições para mT ser período.
Exemplo 1.2.26(1)

Mudar a escala da entrada

Um período após reescalonar

Se f : A → ℝ tem período T, p ∈ ℤ ∖ {0} e q é um inteiro positivo, defina g(x) = f((p/q)x) no domínio E = {x ∈ ℝ : (p/q)x ∈ A}. Então qT é um período de g.

O resultado fornece um período; não afirma que ele seja mínimo. A bancada usa f(x) = {x} e T = 1.

Livro: exemplo 1.2.26(1), p. 30.

Demonstração

  1. Se x ∈ E, então u = (p/q)x pertence a A. Pelo resultado sobre múltiplos inteiros, u ± pT ∈ A e f(u ± pT) = f(u).
  2. Como (p/q)(x ± qT) = u ± pT, os pontos x ± qT pertencem a E. Assim a translação preserva o domínio nos dois sentidos.
  3. Também g(x ± qT) = f(u ± pT) = f(u) = g(x). Como qT > 0, essas são exatamente as condições para qT ser um período de g.
Passo 3 · Exemplo 1.2.26

Periódica não implica período mínimo

O período mínimo, quando existe, é o menor elemento do conjunto dos períodos positivos. Não se deve pressupor que esse conjunto tenha mínimo.

Três comportamentos

Em ℝ, a parte fracionária tem período mínimo 1. Uma função constante tem todo T > 0 como período e nenhum mínimo. A função χℚ, igual a 1 nos racionais e a 0 nos irracionais, tem exatamente os racionais positivos como períodos e também não tem mínimo.

χℚ não pode ser desenhada classificando números decimais da tela como racionais ou irracionais. A bancada utiliza entradas declaradas simbolicamente, como 1/q e √2, e argumentos sobre elas.

Livro: definição 1.2.25 e exemplo 1.2.26, p. 30.

Demonstração

  1. Da definição de piso, ⌊x⌋ ≤ x < ⌊x⌋ + 1. Somar um inteiro k mostra ⌊x + k⌋ = ⌊x⌋ + k; logo {x + k} = {x}. Assim 1 é período. Se T > 0 é período, {T} = {0} = 0, portanto T é inteiro. Os períodos positivos são exatamente os inteiros positivos, cujo mínimo é 1.
  2. Se f(x) = c em todo ℝ, o domínio é preservado por qualquer translação e f(x ± T) = c = f(x) para todo T > 0. Como T/2 também é período e 0 < T/2 < T, não há mínimo.
  3. Para T racional, x ± T é racional se, e somente se, x é racional; portanto χℚ(x ± T) = χℚ(x). Se T > 0 é irracional, χℚ(T) = 0 ≠ 1 = χℚ(0), então T não é período. Todo período T racional positivo admite o período menor T/2, logo não há mínimo.
Passo 4 · Definição 1.2.27

A ordem transportada pela função

Para f : A → ℝ, e quaisquer x₁,x₂ ∈ A com x₁ < x₂, dizemos que f é crescente se f(x₁) ≤ f(x₂), e estritamente crescente se f(x₁) < f(x₂). As versões decrescentes usam ≥ e >, respectivamente. Aqui “crescente” admite igualdade, como no livro.

Uma constante é crescente e decrescente, mas não estritamente monótona num domínio com dois pontos. x² não é monótona em ℝ, mas é estritamente crescente em ℝ₊. O piso é crescente e não é estritamente crescente.

Injetividade e ordem da inversa

Toda função estritamente monótona é injetora. Considerada como bijeção de A sobre f(A), sua inversa é estritamente crescente quando f é estritamente crescente, e estritamente decrescente quando f é estritamente decrescente.

Livro: monotonicidade, p. 31. O resultado sobre a inversa explicita uma consequência das definições e da aula anterior.

Demonstração

  1. Se x₁ ≠ x₂, uma das entradas é menor. A monotonicidade estrita, crescente ou decrescente, impõe saídas diferentes. Portanto f é injetora. Como A → f(A) é sobrejetora por definição, é bijetora e tem inversa h : f(A) → A.
  2. Suponha f estritamente crescente. Dados y₁ < y₂ em f(A), ponha xᵢ = h(yᵢ). Se x₁ = x₂, então y₁ = y₂, absurdo. Se x₁ > x₂, então y₁ = f(x₁) > f(x₂) = y₂, absurdo. Resta h(y₁) < h(y₂).
  3. Suponha f estritamente decrescente. Com a mesma notação, x₁ = x₂ é impossível. Se x₁ < x₂, então y₁ = f(x₁) > f(x₂) = y₂, absurdo. Resta h(y₁) > h(y₂), que é a monotonicidade estritamente decrescente da inversa.
Passo 5 · Proposição 1.2.28

Dos inteiros aos reais

Monotonicidade e homogeneidade

Se f : ℝ → ℝ é estritamente crescente e satisfaz f(nx) = nf(x) para todo x ∈ ℝ e todo n ∈ ℤ, então existe c > 0 tal que f(x) = cx para todo x ∈ ℝ. Necessariamente c = f(1).

A hipótese não é a aditividade f(x + y) = f(x) + f(y). Primeiro a homogeneidade determina f nos racionais. Depois, a ordem e a densidade de ℚ impedem qualquer desvio da reta em uma entrada real.

O ponto destacado fora da reta é uma suposição para obter contradição. Não representa uma função que satisfaça as duas hipóteses. A escolha do racional q é certificada por comparações exatas entre inteiros e √2; as posições na tela são aproximadas.

Livro: proposição 1.2.28 e demonstração, pp. 31–32.

Demonstração

  1. A hipótese com n = 0 dá f(0) = 0. Defina c = f(1). Como 0 < 1 e f é estritamente crescente, 0 = f(0) < f(1) = c.
  2. Dados p ∈ ℤ e n ∈ ℕ com n ≥ 1, temos nf(p/n) = f(p) = pf(1) = pc. Dividindo por n, f(p/n) = c(p/n). Portanto f(q) = cq para todo q ∈ ℚ.
  3. Fixe x ∈ ℝ. Se f(x) < cx, então f(x)/c < x, pois c > 0. Pela densidade de ℚ, existe q racional com f(x)/c < q < x. Por um lado, q < x implica f(q) < f(x). Por outro, f(q) = cq > f(x), contradição.
  4. Se f(x) > cx, escolha q racional com x < q < f(x)/c. A monotonicidade dá f(x) < f(q), mas f(q) = cq < f(x), novamente uma contradição.
  5. Os dois desvios são impossíveis; resta f(x) = cx. Como x foi arbitrário, a igualdade vale em todo ℝ. O coeficiente é positivo e único, pois avaliar em x = 1 obriga c = f(1).
Passo 6 · Corolário 1.2.29

Quando só temos entradas não negativas

Versão em ℝ₊ = [0,+∞)

Se f : ℝ₊ → ℝ é estritamente crescente e f(nx) = nf(x) para todo x ≥ 0 e todo n ∈ ℕ = {0,1,2,…}, então existe c > 0 tal que f(x) = cx para todo x ≥ 0.

Para aplicar a proposição anterior, estendemos f ao eixo negativo de maneira ímpar. É preciso verificar que essa extensão conserva as duas hipóteses.

Livro: corolário 1.2.29, p. 32.

Demonstração

  1. Como antes, f(0) = 0 e f(t) > 0 para t > 0. Defina g : ℝ → ℝ por g(x) = f(x) se x ≥ 0, e g(x) = −f(−x) se x < 0. As fórmulas concordam em zero e g é ímpar.
  2. Se x₁ < x₂ são não negativos, g(x₁) < g(x₂) pela hipótese. Se x₁ < x₂ ≤ 0, então −x₁ > −x₂ ≥ 0; daí f(−x₁) > f(−x₂), e negar dá g(x₁) < g(x₂). Se x₁ < 0 < x₂, temos g(x₁) < 0 < g(x₂). Portanto g é estritamente crescente em ℝ.
  3. Para n ≥ 0 e x ≥ 0, g(nx) = ng(x) pela hipótese sobre f. Para x < 0 e n ≥ 1, g(nx) = −f(n(−x)) = −nf(−x) = ng(x); o caso n = 0 segue de g(0) = 0. Se n = −m < 0, a imparidade e o caso m > 0 dão g(nx) = g(−mx) = −g(mx) = −mg(x) = ng(x).
  4. A proposição 1.2.28 aplica-se a g e fornece g(x) = cx em ℝ, com c = g(1) = f(1) > 0. Restringindo a x ≥ 0, obtemos f(x) = cx.
Passo 7 · Exemplo 1.2.30

Uma aplicação: área e ângulo

Fixe um círculo de raio r > 0 e meça θ em radianos, com uma volta completa igual a 2π. Considere a área orientada S(θ): ângulos negativos têm área negativa, e voltas sucessivas contam a área com multiplicidade.

Consequência das hipóteses de área

Admita S : ℝ → ℝ estritamente crescente, S(nθ) = nS(θ) para todo θ ∈ ℝ e n ∈ ℤ, e S(2π) = πr². Então S(θ) = r²θ/2 para todo θ ∈ ℝ.

Essas propriedades de S são hipóteses geométricas admitidas neste exemplo, como no livro. A figura ilustra suas consequências; não estabelece uma teoria de área nem demonstra essas hipóteses.

Livro: exemplo 1.2.30, p. 32.

Demonstração condicional

  1. Pela proposição 1.2.28 aplicada a S, existe k > 0 tal que S(θ) = kθ para todo θ ∈ ℝ.
  2. Em θ = 2π, as duas expressões para a área dão k·2π = πr². Como 2π ≠ 0, segue k = r²/2.
  3. Substituindo esse valor, S(θ) = r²θ/2 para todo θ ∈ ℝ, inclusive θ < 0 e ângulos com mais de uma volta. A interpretação nesses casos é orientada e conta multiplicidade.
Exercícios · Hipóteses que fazem diferença
  1. Uma função pode ser par e ímpar ao mesmo tempo?
    Ver resolução
    Sim: a função nula. Reciprocamente, se ambas as identidades valem, f(x) = f(−x) = −f(x), então 2f(x) = 0 para todo x. Assim somente a função nula tem ambas as propriedades num mesmo domínio simétrico.
  2. Por que x² em ℝ₊ não satisfaz o corolário de linearidade?
    Ver resolução
    Embora seja estritamente crescente, f(2x) = 4x² e 2f(x) = 2x². Para x > 0, essas expressões diferem. Falha a homogeneidade por inteiros.
  3. Calcule a área orientada para θ = −3π e raio r.
    Ver resolução
    S(−3π) = −3πr²/2: uma volta e meia no sentido negativo. O valor absoluto excede a área do disco porque as voltas contam com multiplicidade.
Laboratório aberto

Digite uma função. Investigue suas propriedades.

Escolha a expressão e o domínio. O explorador reconhece polinômios e famílias elementares, com justificativas algébricas. Expressões mais gerais também podem ser desenhadas, mas recebem “não determinado” nas propriedades que esta versão não consegue decidir.

Use * para multiplicar, ^ para potências, ponto decimal e parênteses. Funções: sin (ou sen), cos, tan, exp, ln, sqrt, cbrt, abs e floor. Constantes: pi e e. Para raízes cúbicas reais negativas, use cbrt(x).

O gráfico usa amostragem numérica e pode omitir detalhes pequenos, valores fora da janela ou trechos perto de singularidades. A tangente é interrompida numericamente perto dos polos. As classificações acima vêm de regras simbólicas para famílias reconhecidas; coincidências visuais não são demonstrações. “Não determinado” não significa “não existe”.
